# Блок-схемы хеш-функций SHA-1 и ГОСТ 34.11-2012

## Для отчёта

| Файл | Содержание |
| --- | --- |
| `sha1.puml` | Дополнение сообщения, расширение блока до 80 слов и 80 раундов сжатия с функциями и константами раундов |
| `gost34_11.puml` | Выбор вектора инициализации, сжатие блоков функцией `gN`, дополнение последнего блока и завершающие `g0(h, N)`, `g0(h, S)`; определения `LPS`, `E` и расписания ключей -- в примечаниях |

Отрендеренные версии лежат в `../img/block_scheme_sha1.svg` и
`../img/block_scheme_gost.svg` и включаются в приложение Б.

## Рендеринг

```
java -jar plantuml.jar -charset UTF-8 -tsvg -o ../img sha1.puml gost34_11.puml
mv ../img/sha1.svg ../img/block_scheme_sha1.svg
mv ../img/gost34_11.svg ../img/block_scheme_gost.svg
```

`-tsvg` предпочтительнее `-tpng`: Typst поддерживает SVG, и в PDF схема
останется векторной.

## Замечания по нотации

- В схеме ГОСТ векторы записываются от старшего байта к младшему, как в
  стандарте и в `gost34_11.rs`; «младшие 512 бит M» -- последние 64 байта
  такой записи. Обращение порядка байтов для строк выполняется в `main.rs` и в
  схему не входит.
- Контрольная сумма обозначена `S`, а не `Σ`, и `xor`, `<>` используются вместо
  `⊕`, `≠` по той же причине, что и в lab2: в шрифтах headless-рендера PlantUML
  этих символов может не оказаться.
- Двух `--` в одной строке примечания быть не должно: PlantUML читает
  `--текст--` как зачёркивание.
