# Блок-схема криптосистемы Мак-Элиса

## Для отчёта

`mceliece.puml` -- сводная блок-схема зашифрования и расшифрования сообщения.
Дополнение и разбиение на блоки, зашифрование `c = m·G' + e`, снятие
перестановки, декодер Паттерсона (синдром, `tau`, укороченный алгоритм
Евклида, многочлен локаторов `sigma`, поиск корней), умножение на `S^-1` и
снятие дополнения показаны одной схемой с ветвлением по направлению.
Генерация ключей и построение кода Гоппы описаны в тексте отчёта.

Отрендеренная версия лежит в `../img/block_scheme.svg` и включается в
приложение Б.

## Рендеринг

```
java -jar plantuml.jar -charset UTF-8 -tsvg -o ../img mceliece.puml
mv ../img/mceliece.svg ../img/block_scheme.svg
```

## Замечания по нотации

- `n`, `k`, `t` -- длина кода, число бит сообщения в блоке и число
  исправляемых ошибок; `ceil(n / 8)` -- число байт шифроблока.
- `L[j]` -- j-й элемент носителя, `g(x)` -- многочлен Гоппы.
- Биты байта нумеруются от младшего к старшему.
- `S^-1`, `P^-1`, `<>`, `sqrt`, `tau`, `sigma` записаны ASCII по той же
  причине, что и в lab2/lab3: в шрифтах headless-рендера PlantUML надстрочных
  символов и `≠` может не оказаться.
